# Dahlia Avatar

Dahlia's companion apps: chat with her through an avatar on the web,
on the desktop, and on Android.

Based on [Project AIRI](https://github.com/moeru-ai/airi) by Moeru AI
(MIT license, see [`LICENSE`](LICENSE)), adapted to Dahlia.

## Get the apps

Download the latest release from
[releases](https://github.com/AleytiaFairlight/Dahlia-avatar/releases):
the Windows installer, the Android APK, and the Kirie test build.
